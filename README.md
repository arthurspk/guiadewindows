## :dart: O guia para alavancar a sua carreira

> O Windows é o sistema operacional mais usado em ambientes corporativos no mundo, e domínio dele — do desktop ao Windows Server — continua sendo pré-requisito em vagas de suporte técnico, administração de sistemas, infraestrutura e DevOps. Este guia reúne documentação oficial, cursos, livros, canais, ferramentas, um capítulo dedicado a PowerShell, outro ao WSL (Windows Subsystem for Linux), projetos práticos, certificações Microsoft e um capítulo sobre como usar IA na prática com Windows — tudo verificado e organizado para quem está começando a administrar sua primeira máquina Windows ou quer aprofundar em automação e ambientes híbridos.

## 🤖 IA na prática

O Windows passou a ter assistentes de IA embutidos no próprio sistema operacional — o Copilot no Windows — além de integrações profundas com PowerShell e o Terminal, o que muda a forma de administrar e automatizar tarefas no dia a dia.

**Para aprender**
- Use o [Copilot no Windows](https://learn.microsoft.com/pt-br/windows/ai/) (documentação oficial de IA do Windows) para tirar dúvidas rápidas sobre configurações, atalhos e recursos do sistema sem sair da tela em que você está.
- Cole um erro de script (ex.: `The term 'Get-InstalledSoftware' is not recognized as the name of a cmdlet`) em um assistente de IA e peça: *"explique a causa provável e mostre a correção linha a linha"*.
- Peça para explicar, comando por comando, um script `.ps1` de um projeto open source que você não escreveu — PowerShell tem sintaxe própria (pipelines de objetos, não texto) e a IA ajuda a entender a lógica por trás de cada cmdlet.
- Peça exercícios práticos: *"me dê um desafio de automação para renomear e organizar arquivos em massa com PowerShell, sem me dar a resposta"* — você tenta, a IA revisa.

**Para trabalhar**
- Ferramentas como [GitHub Copilot](https://github.com/features/copilot) e [Claude Code](https://code.claude.com/docs/en/overview) escrevem scripts PowerShell, tarefas agendadas e manifestos de Diretiva de Grupo a partir de uma descrição em linguagem natural — sempre revise antes de rodar em produção, principalmente scripts que alteram o Registro.
- No [Windows Terminal](https://learn.microsoft.com/en-us/windows/terminal/), é possível integrar assistentes de IA via extensões e MCP para gerar comandos direto na linha de comando, tanto em PowerShell quanto dentro do WSL.
- O [Microsoft Copilot para Microsoft 365](https://www.microsoft.com/pt-br/microsoft-365/copilot) auxilia administradores a gerar relatórios e resumir logs de eventos do Windows Server e do Intune.
- Depois de aceitar qualquer sugestão de IA para um script, rode um linter como o [PSScriptAnalyzer](https://github.com/PowerShell/PSScriptAnalyzer) antes de agendar ou distribuir o script em outras máquinas.

**Limites e boas práticas**
- IA **inventa cmdlets, parâmetros e caminhos de Registro** com frequência, principalmente para versões recentes do PowerShell e do Windows 11. Confira sempre na [referência oficial do PowerShell](https://learn.microsoft.com/pt-br/powershell/).
- Nunca peça para uma IA gerar um script com credenciais, chaves de API ou senhas embutidas em texto puro; use o [Secret Management](https://learn.microsoft.com/en-us/powershell/utility-modules/secretmanagement/overview) do PowerShell ou o Gerenciador de Credenciais do Windows.
- Desconfie de um script sugerido que peça para desativar o Windows Defender, o UAC ou políticas de segurança "só para funcionar" — isso raramente é necessário e expõe a máquina a risco.
- Sempre teste um script de automação em uma VM ou no [Windows Sandbox](https://learn.microsoft.com/en-us/windows/security/application-security/application-isolation/windows-sandbox/) antes de rodar em uma máquina de produção ou em massa via GPO/Intune.
